## 1. Statement of Methodological Principles

To eliminate data leakage, prevent unintentional distribution shortcuts, and avoid optimistic bias, Phase 6 formally establishes a **five-tier evaluation hierarchy**. 

Every evaluation conducted within the LX-DFD project must strictly assign experimental data to one of these five mutually exclusive tiers:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        LX-DFD EVALUATION TIERS                         │
├────────────────────────────────┬───────────────────────────────────────┤
│ Tier 1: In-Domain Validation   │ Model selection & early stopping ONLY │
├────────────────────────────────┼───────────────────────────────────────┤
│ Tier 2: In-Domain Held-Out     │ Native distribution benchmark         │
├────────────────────────────────┼───────────────────────────────────────┤
│ Tier 3: Cross-Dataset          │ Domain/sensor shift benchmark         │
├────────────────────────────────┼───────────────────────────────────────┤
│ Tier 4: Unseen-Generator       │ Generative paradigm shift (LOGO)      │
├────────────────────────────────┼───────────────────────────────────────┤
│ Tier 5: Corruption Robustness  │ Real-world transmission degradation   │
└────────────────────────────────┴───────────────────────────────────────┘
```

## 2. Specification of the Five Evaluation Tiers

### 2.1 Tier 1: In-Domain Validation (`data/splits_v2/val.csv`, $N=1,897$)
- **Purpose**: Hyperparameter tuning, learning rate scheduling, and early stopping checkpoint selection (`val_metrics['roc_auc'] > best_val_auc`).
- **Composition**: $847$ Real FFHQ faces and $1,050$ Fake StyleGAN2 faces, strictly separated from training via zero-leakage identity and perceptual hash clustering.
- **Strict Constraint**: Under no circumstances may Tier 2, 3, 4, or 5 data be consulted during model checkpoint selection.

### 2.2 Tier 2: In-Domain Held-Out Testing (`data/splits_v2/test.csv`, $N=1,956$)
- **Purpose**: Final reporting of model classification performance on the native training distribution.
- **Composition**: $883$ Real FFHQ faces and $1,073$ Fake StyleGAN2 faces.
- **Metrics Reported**: Clean Accuracy, Precision, Recall, F1, ROC-AUC, PR-AUC, Confusion Matrix ($TN, FP, FN, TP$), Brier Score, and Expected Calibration Error (ECE).

### 2.3 Tier 3: Cross-Dataset Evaluation
- **Purpose**: Measuring resilience to domain shifts, including camera sensor variations, geographic demographic distributions, compression history, and color grading.
- **Requirement**: Evaluates authentic human portraits from disjoint photographic sources (e.g., IMDB-WIKI, CelebA, LFW) against synthetic images generated by the *same* family seen in training.
- **Significance**: Distinguishes true deepfake artifact detection from background or sensor shortcut learning.

### 2.4 Tier 4: Unseen-Generator Evaluation (Leave-One-Generator-Out, LOGO)
- **Purpose**: The definitive test of generalized deepfake detection. Measures whether the detector recognizes synthetic facial synthesis when generated by an **entirely unobserved generative paradigm**.
- **Protocol**:
  - The evaluation set must contain generator architectures whose latent spaces, loss formulations, and upsampling mechanisms were absent from the training set (e.g. evaluating on Flow-Matching FLUX.1 when trained on StyleGAN2 and Latent Diffusion).
  - Evaluated on $1:1$ balanced cohorts ($N_{\text{real}} = N_{\text{fake}}$) to ensure baseline chance accuracy is exactly $50.0\%$ and chance ROC-AUC is $0.5000$.
- **Exploratory Status of Phase 4/5 Benchmark**:
  - The existing $800$-image OpenRL/DeepFakeFace benchmark ([`data/unseen_generator_test/manifest.csv`](file:///c:/Users/nandi/Desktop/DEEPFAKE%20DETECTION/data/unseen_generator_test/manifest.csv)) was utilized in Phases 4 and 5 to evaluate and reject models (e.g. rejecting Spectral Dropout).
  - In strict adherence to scientific rigor, this benchmark is designated as **Exploratory Evidence**. Any new model trained on diverse data will be evaluated on this set for direct historical comparison, but final confirmation requires an independent, unobserved Tier 4 benchmark (e.g. FLUX.1 / Midjourney v6).

### 2.5 Tier 5: Systematic Corruption Robustness
- **Purpose**: Measuring detection stability when images undergo real-world social-media transmission and physical degradation.
- **Protocol**: 14 standardized stress conditions across 4 distortion axes:
  1. **JPEG Compression**: Quality factors $q \in \{90, 75, 50, 30\}$.
  2. **Resolution Downsampling**: Scale factors $s \in \{0.75\times, 0.50\times\}$.
  3. **Optical / Motion Blur**: Gaussian blur radii $r \in \{1.5, 3.0\}$.
  4. **Sensor Noise**: Additive Gaussian noise $\sigma \in \{0.01, 0.05, 0.10\}$.
  5. **Photometric Perturbations**: Brightness and Contrast scaling $\{0.7\times, 1.3\times\}$.
- **Standardized Metrics**:
  $$\text{Mean AUC Drop} = \frac{1}{14}\sum_{i=1}^{14} \max\left(0, \text{AUC}_{\text{clean}} - \text{AUC}_{\text{corrupted}, i}\right)$$
  $$\text{Composite Robustness Score} = \max\left(0, 1.0 - \text{Mean AUC Drop}\right)$$

## 3. Mandatory Preprocessing & Face Alignment Standard

To eliminate the spatial-frequency squashing shortcut discovered during the Phase 6 audit:

1. **Automated Face Detection**: Every image must pass through the YuNet face detector ([`yunet.onnx`](file:///c:/Users/nandi/Desktop/DEEPFAKE%20DETECTION/yunet.onnx)).
2. **Aspect-Ratio-Preserving Square Bounding Box**:
   - The detected face bounding box $[x, y, w, h]$ is expanded by a standard margin factor ($1.25\times$) while maintaining an exact $1:1$ square aspect ratio.
   - Bounding boxes extending beyond image boundaries are padded via mirror reflection or edge padding.
3. **Bilinear Normalization**:
   - The square face crop is resized to $(224 \times 224)$ pixels using bilinear interpolation.
   - Normalized using ImageNet statistics: $\mu = [0.485, 0.456, 0.406]$, $\sigma = [0.229, 0.224, 0.225]$.
4. **Enforcement**: Naive anisotropic resizing directly on uncropped full-scene images is strictly prohibited in all future evaluation scripts.

## 4. Metric Calculation & Statistical Rigor Rules

1. **Fixed Decision Threshold**:
   - All operational classification metrics (Accuracy, Precision, Recall, F1) must be computed at a fixed threshold of **$\tau = 0.50$** ($\hat{y} = \mathbb{I}(p_{\text{fake}} \ge 0.50)$).
   - Post-hoc threshold tuning on external evaluation splits is strictly prohibited.
2. **Disaggregated Per-Generator Reporting**:
   - Because pooling all generator fakes against a shared real control cohort creates class imbalance ($1:K$), results must always be disaggregated per generator.
   - Macro-averages must be computed across valid balanced generator cohorts:
     $$\text{AUC}_{\text{macro}} = \frac{1}{K}\sum_{k=1}^K \text{AUC}(G_k)$$
3. **Statistical Uncertainty**:
   - Every reported ROC-AUC and Accuracy metric must be accompanied by non-parametric bootstrap $95\%$ confidence intervals ($B=1,000$ resamples, $\alpha=0.05$).
   - Statistical claims of superiority must demonstrate disjoint or non-overlapping confidence intervals.
