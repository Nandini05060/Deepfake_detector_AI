## 1. Scientific Motivation & Core Hypothesis

### 1.1 The Root Cause of Generator Overfitting
In Phase 4, empirical evaluation revealed a severe **generalization gap**:
- When evaluated on in-domain StyleGAN/StyleGAN2 faces, Proposed LX-DFD achieves **$0.9998$ ROC-AUC**.
- When evaluated on unseen Latent Diffusion (Stable Diffusion v1.5), LX-DFD collapses to **$0.5046$ ROC-AUC** (chance level).

**Mechanistic Explanation**:
StyleGAN architectures upsample latent features using transposed convolutions, creating periodic, phase-locked grid artifacts that manifest as high-energy harmonic spikes at narrow coordinate locations in the 2D DCT log-magnitude spectrum. The 4-layer Frequency CNN rapidly memorizes these specific frequency spikes as primary discriminative features. When presented with images generated by diffusion models (which construct images via iterative reverse denoising in a latent space without transposed convolutions), these narrow spikes are absent. Consequently, the frequency branch fails to detect the fake and defaults to predicting authentic real.

### 1.2 Core Hypothesis
> **Hypothesis**:  
> Stochastic rectangular occlusion of the 2D DCT log-magnitude spectrum (`SpectralDropout2D`) during training prevents the Frequency CNN from relying on narrow, localized frequency spikes. By randomly masking contiguous frequency bands, the network is forced to learn distributed, broadband harmonic decay patterns and macro-energy relationships that persist across diverse generative paradigms.

## 2. Architectural Verification & Layer Wiring

### 2.1 Code Wiring Audit
The module is implemented in [`src/models/frequency_branch.py`](file:///c:/Users/nandi/Desktop/DEEPFAKE%20DETECTION/src/models/frequency_branch.py#L6-L32):

```python
class SpectralDropout2D(nn.Module):
    def __init__(self, p: float = 0.2, block_size_range: tuple = (16, 48)):
        super().__init__()
        self.p = p
        self.block_size_range = block_size_range

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        if not self.training or self.p <= 0.0:
            return x
        
        B, C, H, W = x.shape
        mask = torch.ones_like(x)
        for b in range(B):
            if torch.rand(1).item() < self.p:
                bh = torch.randint(self.block_size_range[0], self.block_size_range[1] + 1, (1,)).item()
                bw = torch.randint(self.block_size_range[0], self.block_size_range[1] + 1, (1,)).item()
                y0 = torch.randint(0, max(1, H - bh), (1,)).item()
                x0 = torch.randint(0, max(1, W - bw), (1,)).item()
                mask[b, :, y0:y0+bh, x0:x0+bw] = 0.0
                
        return x * mask
```

### 2.2 Critical Verification Checks
1. **Model Hierarchy**:
   `LXDFDModel` $\rightarrow$ `FrequencyBranch` $\rightarrow$ `self.spectral_dropout` $\rightarrow$ `SpectralDropout2D`.
2. **Train/Eval Guard**:
   `if not self.training or self.p <= 0.0: return x`.
   - During `train()`: Stochastic masking is active.
   - During `eval()`: The layer is an exact identity function ($x$). Zero spectral dropout is applied during validation, testing, or corruption benchmarking.
3. **Occlusion Dimensions**:
   Mask block size is stochastically sampled between $[16, 48] \times [16, 48]$ pixels in the $224 \times 224$ DCT log-magnitude map.
4. **Device Consistency**:
   `mask = torch.ones_like(x)` ensures the mask resides on the exact same CUDA device and tensor dtype as the input feature map.

## 3. Training Protocol & Compute Specifications

### 3.1 Controlled Experimental Setup
To strictly isolate the impact of 2D DCT Spectral Dropout, all other variables are held identical to the Phase 2 baseline:
- **Architecture**: Dual-Branch Spatial-Frequency LX-DFD with Attention Fusion.
- **Augmentation Mode**: Standard spatial augmentations (`--aug-mode standard`).
- **Dropout Probability**: $p = 0.20$.
- **Training Partition**: `data/splits_v2/train.csv` ($N=9,037$, zero-leakage cluster split).
- **Validation Partition**: `data/splits_v2/val.csv` ($N=1,897$).
- **Optimizer**: AdamW ($\text{lr} = 1\times 10^{-4}$, $\text{weight\_decay} = 1\times 10^{-4}$).
- **Scheduler**: Cosine Annealing with 2-epoch linear warmup.
- **Batch Size**: 32.
- **Epochs**: 15.
- **Random Seed**: 42 (strictly seeded across Python, NumPy, PyTorch, CUDA).
- **Target Device**: NVIDIA GeForce RTX 3050 Laptop GPU with PyTorch Automatic Mixed Precision (AMP).

### 3.2 Non-Destructive Checkpoint Policy
- **Target Checkpoint**: `checkpoints/lxfd_attention_standard_spectral_dropout_best.pt`
- **History Log**: `checkpoints/lxfd_attention_standard_spectral_dropout_history.json`
- **Integrity Rule**: Existing baseline checkpoints (`lxfd_attention_standard_best.pt`, `lxfd_attention_robustness_v2_best.pt`, `efficientnet_best.pt`, `dense_cnn_best.pt`, `simple_cnn_best.pt`) are read-only and will never be overwritten.
- **Model Selection**: Checkpoint selection is strictly based on validation ROC-AUC (`val_metrics['roc_auc'] > best_val_auc`).

## 4. Evaluation Suite Specification

The newly trained model will be evaluated alongside the three key benchmark models:
1. **EfficientNet-B0 Baseline** (Spatial RGB)
2. **LX-DFD Standard** (Spatial-Frequency Baseline)
3. **LX-DFD Robustness v2** (Spatial-Frequency with Perturbation Training)
4. **LX-DFD Spectral Dropout** (Proposed regularized frequency model)

### 4.1 Evaluation Dimensions
1. **Clean In-Domain Test Split** (`data/splits_v2/test.csv`, $N=1,956$):
   - Accuracy, Precision, Recall, F1, ROC-AUC, PR-AUC.
   - Confusion matrix ($TN, FP, FN, TP$).
   - Brier Score, Expected Calibration Error (ECE), Log Loss.
2. **Perturbation & Corruption Benchmark** (14 Stress Conditions):
   - Gaussian Noise ($\sigma = 0.01, 0.02, 0.05$).
   - JPEG Compression ($q = 30, 50, 75$).
   - Gaussian Blur ($r = 1.0, 1.5, 3.0$).
   - Color Jitter, Saturation, Brightness, Downsampling.
3. **External Unseen-Generator Benchmark** (`data/unseen_generator_test/`, $N=800$):
   - Disaggregated ROC-AUC and Accuracy for Stable Diffusion v1.5, InsightFace Swap, and SD Inpainting.
   - Macro-average ROC-AUC and 95% bootstrap confidence intervals.
4. **Operational Efficiency**:
   - Model parameter count and inference latency (ms/frame).

## 5. Go/No-Go Decision Criteria

| Metric | Baseline LX-DFD | Target Success Threshold | Scientific Decision Impact |
|---|:---:|:---:|---|
| **Clean In-Domain ROC-AUC** | $0.9998$ | $\ge 0.9900$ | Verifies that spectral regularization does not degrade clean discrimination. |
| **Clean In-Domain Accuracy** | $99.39\%$ | $\ge 98.00\%$ | Preserves high classification utility on primary task. |
| **Stable Diffusion v1.5 AUC** | $0.5046$ | $\ge 0.5500$ | Primary test of hypothesis: breaking frequency grid dependence on diffusion. |
| **Unseen Macro ROC-AUC** | $0.5771$ | $\ge 0.6000$ | Overall cross-generator transfer improvement. |
| **Corruption Robustness** | $0.9185$ | $\ge 0.9200$ | Demonstrates resilience to high-frequency perturbation. |

**Decision Protocol**:
- **Adopt Spectral Dropout**: If external macro ROC-AUC improves by $\ge +0.02$ without clean AUC falling below $0.9900$.
- **Negative Result Protocol**: If spectral dropout fails to improve cross-generator transfer, the negative result will be documented honestly without post-hoc tuning against the external test set.
