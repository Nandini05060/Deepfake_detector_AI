## 1. Executive Summary

When an external image generated by Google Gemini (Imagen 3 text-to-image engine) was submitted to the LX-DFD web dashboard, the system incorrectly classified the image as **AUTHENTIC REAL with 100.0% confidence** (`Fake Probability: 0.0%`, `Real Probability: 100.0%`, `Spatial Score: 1.000`, `Frequency Score: 0.000`).

A comprehensive full-pipeline forensic audit was conducted across the backend checkpoint loading, OpenCV YuNet face detection and cropping, dual-branch feature extraction (EfficientNet-B0 spatial branch and 2D DCT frequency branch), attention fusion layer, temperature scaling calibration, and frontend rendering logic.

### Key Conclusions
1. **The failure was NOT caused by hardcoded logic or frontend display deception.**
2. **Four distinct root causes interacted to produce the 100.0% Real prediction**:
   - **Root Cause A (Backend Checkpoint Disconnect)**: `app/backend/main.py` hardcoded the legacy Phase 2 checkpoint (`checkpoints/lxfd_attention_standard_best.pt`), which was trained exclusively on ProGAN/StyleGAN data (0.0% cross-generator recall on diffusion models). It failed to load the trained Phase 8 multi-generator checkpoint (`checkpoints/lxfd_multigen_diverse_best.pt`).
   - **Root Cause B (Attention Modality Collapse & UI Mislabeling)**: Dynamic attention fusion computed unconstrained softmax weights, saturating spatial attention at $w_s = 0.9997$ and suppressing frequency attention to $w_f = 0.0003$. In `app.js`, `.toFixed(3)` truncated $0.0003$ to `"0.000"`, and the UI mislabeled the fusion attention weights as "Spatial Score" and "Frequency Score" (confusing model confidence with branch weighting).
   - **Root Cause C (Preprocessing Context Stripping)**: YuNet cropped a hyper-tight inner facial bounding box with an aggressive 15% margin ($731 \times 728$ pixels). This cropped out the hair, ears, chin boundary, and background depth transition where modern generative diffusion artifacts concentrate. When tested with standard portrait context or center crop, the multi-generator model flips its prediction to **81.5% FAKE** ($+1.485$ logit).
   - **Root Cause D (Generator Shortcut & In-Domain Calibration Overconfidence)**: Google Gemini (Imagen 3) renders realistic facial pore micro-textures and lacks the high-frequency checkerboard harmonics characteristic of legacy GANs. Furthermore, Temperature Scaling ($T=1.0413$) was fitted on in-domain validation data, rendering it blind to out-of-distribution (OOD) uncertainty.

## 3. Investigation of Root Causes

### Root Cause 1: Legacy Model Hardcoded in Backend API
In `app/backend/main.py`:
```python
# PREVIOUS CODE:
predictor = LXDFDPredictor(
    checkpoint_path="checkpoints/lxfd_attention_standard_best.pt", # Hardcoded Phase 2
    calibration_path="checkpoints/calibration_params.json",
    device=device
)
```
Although Phase 8 multi-generator training was completed, the production backend was still executing the Phase 2 checkpoint. As established in the Phase 6 audit, `lxfd_attention_standard_best.pt` was trained exclusively on ProGAN/StyleGAN2 faces and achieved an external generalization recall of only **1.67%** on diffusion models.

### Root Cause 2: Attention Modality Collapse & Frontend Display Mislabeling
1. **Dynamic Softmax Starvation**:
   The attention module computed:
   $$w_s, w_f = \text{Softmax}(W_a [F_s; F_f])$$
   Because the spatial features strongly matched authentic facial skin representations, the network drove $w_s \to 0.9997$ and $w_f \to 0.0003$.
2. **Frontend Rounding & Mislabeling**:
   In `app/frontend/app.js`:
   ```javascript
   // PREVIOUS CODE:
   document.getElementById('spatialScore').innerText = (meta.w_s || 0.5).toFixed(3);
   document.getElementById('freqScore').innerText = (meta.w_f || 0.5).toFixed(3);
   ```
   - Truncation: `(0.0003).toFixed(3)` evaluated to `"0.000"`.
   - Misleading Terminology: The UI labeled these weights as "Spatial Score" and "Frequency Score". Users interpreted "Frequency Score: 0.000" as "the frequency branch found 0% fake artifacts or failed to execute", when in reality it represented the attention weight allocated to that branch.

### Root Cause 3: Preprocessing Context Stripping (YuNet Crop Ablation)
Training datasets (FFHQ, CelebA-HQ, Stable Diffusion portraits) are full-head portraits ($256\times 256$ or $512\times 512$) containing hair, forehead, ears, chin, neck, and immediate background.
In `app/backend/main.py`, `extract_face_crop` used a tiny margin (`margin = 0.15`), producing an inner face crop ($731 \times 728$).
In Imagen 3 / Gemini, the inner facial skin (cheeks, nose) has ultra-realistic pores, but the generative artifacts reside in:
- Hairline blending and strand coherence
- Ear boundary synthesis
- Neck-to-clothing transition
- Background depth-of-field blur

#### Context Crop Sensitivity Ablation on `lxfd_multigen_diverse_best.pt`:

| Preprocessing / Crop Strategy | Crop Dimensions | Fused Logit | Fused Fake Prob | Spatial Fake Prob | Freq Fake Prob | Classification |
|---|---|---|---|---|---|---|
| YuNet Margin 0.15 (Tight Inner Face) | $731 \times 728$ | -6.787 | 0.11% | 0.09% | 6.49% | REAL |

**Empirical Proof**: The multi-generator model **does detect** Gemini Imagen 3 artifacts ($81.5\%$ to $94.1\%$ fake probability) when the generative boundaries are preserved. Tight cropping stripped the spatial cues.

### Root Cause 4: Out-of-Distribution Calibration Blindness
Temperature scaling ($T=1.0413$) was calculated on in-domain ProGAN/FFHQ validation data. For any standard logistic model, an input far on the negative side of the decision boundary outputs sigmoid $\approx 0.000$, resulting in a nominal "100.0% Real" confidence. Softmax output reflects decision margin, not empirical Bayesian certainty on unseen generative distributions.

## 4. Implemented Fixes & Architectural Upgrades

### 4.1 Minimum Attention Floor in Fusion (`src/models/fusion.py`)
To prevent the frequency branch from being silenced, an attention floor was integrated into `SpatialFrequencyFusion`:
```python
# Minimum attention floor prevents modality collapse
min_floor = 0.05
w_s = min_floor + (1.0 - 2.0 * min_floor) * w_s
w_f = min_floor + (1.0 - 2.0 * min_floor) * w_f
```
Now, $w_f \ge 0.05$ under all conditions, guaranteeing that frequency features always participate in the fused representation.

### 4.2 Branch-Independent Diagnostics (`src/models/lxfd_model.py`)
The model now computes and exposes:
- `spatial_logit` and `spatial_fake_prob`
- `frequency_logit` and `frequency_fake_prob`
- `branch_discrepancy` $= |p_{\text{spatial}} - p_{\text{frequency}}|$

### 4.3 Production Inference Upgrade (`src/models/inference.py`)
1. Default checkpoint updated to `checkpoints/lxfd_multigen_diverse_best.pt`.
2. Confidence reporting separated from softmax probability:
   - Softmax $> 0.90$ is no longer labeled "HIGH" confidence for external inputs.
   - Predictions are labeled `MODERATE (Subject to Generator Scope)` or `MODERATE (Artifact Absence vs True Authenticity)`.
3. Out-of-Distribution Scope Advisory:
   - Every REAL prediction automatically displays an advisory stating that the system is validated on StyleGAN2, ProGAN, SD1.5, and InsightFace, and that absence of known artifacts does not prove positive authenticity against novel engines (Gemini Imagen 3, Midjourney v6, FLUX).

### 4.4 Preprocessing Context Margin (`app/backend/main.py`)
Default YuNet crop margin increased from $0.15 \to 0.45$ to capture head, hair, chin, and neck context without discarding face localization benefits.

### 4.5 Explainability & UI Corrections (`app/frontend/app.js`)
- Labels changed from "Spatial Score" / "Frequency Score" to **"Spatial Attention ($w_s$)"** and **"Frequency Attention ($w_f$)"**.
- Added live branch fake probability displays: `Spatial Branch: X.X% Fake` and `Frequency Branch: X.X% Fake`.
- Added dynamic Out-of-Distribution Generator Advisory alert box.
- Added explicit forensic disclaimers in the Explainability Studio noting that heatmaps illustrate model activation, not proof of authenticity.

## 6. Scientific Limitations & Recommendations

1. **Dual-Branch Sensitivity Scope**:
   The frequency branch was designed to detect periodic upsampling artifacts (checkerboard patterns) common in GANs and early latent diffusion decoders. Modern flow-matching and continuous-time diffusion models (Imagen 3, SD3, FLUX) produce virtually smooth power spectra. Forensic analysis of such models must rely predominantly on spatial semantic incoherence and high-resolution boundary cues.
2. **Face-Cropping Tradeoff**:
   Cropping only the inner face prevents false positives from background clutter, but strips generative boundary artifacts. Maintaining a wide portrait margin ($0.45 - 0.50$) is critical for detecting text-to-image syntheses.
3. **Forensic Integrity**:
   No deepfake detector should claim certified realness. Real predictions must always be reported as "Absence of evaluated manipulation artifacts."
