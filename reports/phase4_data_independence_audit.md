## 1. Forensic Audit of Primary In-Domain Dataset

To guarantee that external evaluation datasets are genuinely independent of the training data, we conducted a forensic audit of the primary dataset (`Final Dataset`) utilized in Phases 1–3.

### 1.1 Dataset Provenance & Decomposition
- **Kaggle Source**: `kshitizbhargava/deepfake-face-images` (Version 1).
- **Original Upstream Origin**: Verified from raw paths in `Final Dataset/dataset.csv`:
  ```
  /kaggle/input/stylegan-and-stylegan2-combined-dataset/Final Dataset/...
  ```
- **Total Images**: 12,890 images (7,000 FAKE, 5,890 REAL).
- **Image Resolution**: Clean, pre-cropped $256 \times 256$ JPEG images.

### 1.2 Filename Taxonomy and Real/Fake Origin Analysis

Forensic regex pattern matching across all 12,890 images revealed the exact underlying distributions:

```
+--------------------+---------------------+--------------------+--------------------+
| Class              | Filename Structure  | Sample Count       | Inferred Origin    |
+--------------------+---------------------+--------------------+--------------------+
| REAL               | 5-digit integer     | 2,945 base images  | FFHQ (Flickr-Faces |
|                    | (e.g. 01149.jpg)    |                    | -HQ Dataset)       |
| REAL               | real_X_aug_Y.jpg    | 2,945 augmented    | Transformed FFHQ   |
+--------------------+---------------------+--------------------+--------------------+
| FAKE               | 10-char alphanumeric| 3,500 base images  | StyleGAN &         |
|                    | (e.g. 001DDU0NI4.jpg|                    | StyleGAN2          |
| FAKE               | fake_X_aug_Y.jpg    | 3,500 augmented    | Transformed GAN    |
+--------------------+---------------------+--------------------+--------------------+
```

### 1.3 Key Forensic Findings:
1. **Real Images are 100% FFHQ**: The 5-digit naming pattern (`00000.jpg` to `69999.jpg`) corresponds to the Flickr-Faces-HQ (FFHQ) dataset created by NVIDIA (Karras et al., 2019).
2. **Fake Images are StyleGAN and StyleGAN2**: The alphanumeric filenames match standard hash filenames exported by early StyleGAN and StyleGAN2 web demonstrations (such as *ThisPersonDoesNotExist.com* and official StyleGAN sample dumps).
3. **Augmentation Groups**: Half of the dataset consists of deterministic horizontal flips, rotations, and color adjustments applied to the 2,945 real and 3,500 fake base images. In Phase 2, `create_leak_free_splits.py` grouped these into cluster IDs, ensuring 0% data leakage across train, validation, and test splits.

## 2. Potential Data Overlap & Leakage Risks in Candidate Datasets

When evaluating external datasets, researchers often unknowingly contaminate their test results by utilizing candidate datasets that share the same base images.

### 2.1 FFHQ Overlap Risk (High Severity)
- **Problem**: Many public "deepfake face" collections on Kaggle, Hugging Face, and academic repositories borrow their real faces directly from the 70,000-image FFHQ repository.
- **Impact**: If an external evaluation benchmark uses FFHQ images for its "real" class, the real images may overlap with the 2,945 FFHQ faces used in LX-DFD's training split.
- **Audit Verification Requirement**: Any candidate real face dataset must be cross-referenced against the master MD5 hash index (`data/metadata.csv`) of the 12,890 training images. Any matching MD5 hash or perceptual dHash distance $\le 4$ must be purged immediately.

### 2.2 CelebA and CelebA-HQ Overlap Risk (Moderate Severity)
- **Problem**: CelebA consists of 202,599 celebrity images. While largely distinct from Flickr users, celebrities occasionally appear in Flickr collections, and CelebA-HQ re-sampled 30,000 CelebA images.
- **Audit Verification Requirement**: Check subject identity overlap using face recognition embeddings (e.g. ArcFace / FaceNet) if CelebA images are used.

### 2.3 StyleGAN / StyleGAN2 Generator Overlap Risk (Severe Generalization Bias)
- **Problem**: Testing a model on an external dataset that was generated by StyleGAN2 does **not** evaluate unseen-generator generalization—it merely evaluates cross-dataset transfer of the *same* generator.
- **Genuine Unseen Generators Relative to LX-DFD Training**:
  - **StyleGAN3**: Fundamentally redesigned anti-aliasing architecture (eliminates transposed conv artifacts).
  - **Diffusion Models**: Stable Diffusion (v1.5, SDXL), Midjourney (v5, v6), DALL-E 3, FLUX.1.
  - **Facial Manipulation Pipelines**: FaceForensics++ (Deepfakes, Face2Face, FaceSwap, NeuralTextures), Celeb-DF v2.
  - **Audio-Driven Video Talking Heads**: Wav2Lip, SadTalker.

## 3. Data Integrity & Leakage Verification Rules

Before any external dataset is evaluated by LX-DFD, the evaluation pipeline enforces the following three-tier integrity check:

```
                                  EXTERNAL DATA AUDIT
                                           │
         ┌─────────────────────────────────┼─────────────────────────────────┐
         ▼                                 ▼                                 ▼
   [Tier 1: MD5]                    [Tier 2: dHash]                  [Tier 3: Metadata]
 Exact Byte Hash Match           Perceptual Similarity            Generator Family Tagged
 (Rejects bitwise duplicates)    (Distance <= 4 purged)           (Rejects StyleGAN1/2 fakes)
```

1. **Exact Duplicate Purge (MD5)**: Every external image's MD5 checksum is compared against the 12,890 training hashes. Any image with an identical MD5 is rejected.
2. **Perceptual Near-Duplicate Purge (dHash)**: 64-bit difference hashes are computed. Any pair with Hamming distance $\le 4$ is flagged as an augmented variant and rejected.
3. **Generator Taxonomy Enforcement**: Any dataset claiming "unseen generator" capabilities must provide ground-truth metadata documenting the generative algorithm. Datasets with unverified or mixed generator tags are restricted to general cross-domain benchmarks.
